# Agent 7 设计指导原则（V1）

本版指导原则以“数据优先、隐喻其次、装饰最少”为核心，强调限制维度、保持留白与清晰的层次结构，适用于信息可视化风格的隐喻插画（非写实）。以下原则直接衍生出固定的英文 Prompt 要求（Prompt0）。

- 数据优先：
  - 将数据表达置于首位，隐喻用于承载与引导理解，装饰仅做点缀。
  - 每一个数据映射应与唯一的视觉通道一一对应，避免通道复用和歧义。

- 维度限制与留白：
  - 可视通道总数控制在 3–4 个以内（如 position/size/lightness/color/texture/orientation/shape）。
  - 移除装饰性背景，留出充足的留白以提升信息可读性。

- 层次结构：
  - 画面需具备清晰的前景/中景/背景层次，突出数据要素。
  - 视觉权重建议：数据 ~70%，隐喻 ~20%，装饰 ~10%。

- 风格与标注：
  - 采用信息图风格的抽象矢量图形，非写实、边缘清晰。
  - 使用简洁和谐的配色；最少化注释与文本，不出现大段文字。

- 行为与动态表达：
  - 针对数据事实（如 增长/下降/波动/平稳/峰值），选择简练、可控的动态视觉词（如 rising/shrinking/oscillating/steady/spiking）。

- 注释化映射：
  - 将数据映射（字段、子元素、通道）改写为自然语言的“可视注释”，明确“数据字段 → 视觉通道”的对应关系，并嵌入隐喻主体以强化可读性。

- 一致性锚点：
  - 在结尾加入稳定的风格锚点（如 infographic, clean vector graphics, abstract minimalism, data visualization clarity, cinematic clarity），确保跨图一致。
